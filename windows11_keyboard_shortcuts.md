# Windows 11 — commands & functions that have a keyboard shortcut

Source: Microsoft Support — “Keyboard shortcuts in Windows” (high-confidence canonical list).  
https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec

> Notes for implementation:
> - Some shortcuts vary by OEM keyboard, language/IME, and feature availability (Game Bar, HDR, etc.).
> - Many “text editing” shortcuts depend on the focused app/control, but are effectively universal.

---

## 1) Core system surfaces

| Shortcut | Action |
|---|---|
| `Win` | Open/close Start |
| `Ctrl+Esc` | Open Start (alternative) |
| `Win+S` | Search |
| `Win+R` | Run dialog |
| `Win+I` | Settings |
| `Win+E` | File Explorer |
| `Win+X` | Power User (Quick Link) menu |
| `Ctrl+Shift+Esc` | Task Manager |
| `Ctrl+Alt+Del` | Security screen (lock, switch user, sign out, Task Manager, etc.) |
| `Win+L` | Lock PC |

---

## 2) Window switching / focus / navigation

| Shortcut | Action |
|---|---|
| `Alt+Tab` | Switch between open windows |
| `Ctrl+Alt+Tab` | Show all open apps; switch with arrows |
| `Alt+Esc` | Cycle windows in the order opened |
| `Alt+F4` | Close active window (or shutdown prompt on desktop) |
| `Alt+Space` | Window menu (Move/Size/Minimize/Maximize/Close) |
| `F6` | Cycle focus elements in a window/desktop |
| `Alt+Left` | Back (many apps) |
| `Alt+Right` | Forward (many apps) |
| `Alt+PageUp` | Up one screen |
| `Alt+PageDown` | Down one screen |

---

## 3) Snap, multitasking, desktops, and monitors

| Shortcut | Action |
|---|---|
| `Win+Tab` | Task View |
| `Win+Z` | Snap Layouts (Windows 11) |
| `Win+Left` | Snap window left |
| `Win+Right` | Snap window right |
| `Win+Up` | Maximize |
| `Win+Down` | Minimize / restore |
| `Win+Home` | Minimize all except active window (toggle) |
| `Win+M` | Minimize all windows |
| `Win+Shift+M` | Restore minimized windows |
| `Win+Shift+Left` | Move window to left monitor |
| `Win+Shift+Right` | Move window to right monitor |
| `Win+P` | Project (display mode picker) |
| `Win+Ctrl+D` | New virtual desktop |
| `Win+Ctrl+Left` | Switch desktop left |
| `Win+Ctrl+Right` | Switch desktop right |
| `Win+Ctrl+F4` | Close current virtual desktop |

## 4) Desktop, notification, quick settings, widgets

| Shortcut | Action |
|---|---|
| `Win+D` | Show/hide desktop |

| `Win+A` | Open Quick Settings (Action Center style panel in Windows 11) |

| `Win+W` | Widgets |

## 5) Clipboard, emoji, dictation, input language

| Shortcut | Action |
|---|---|
| `Win+V` | Clipboard history |
| `Win+.` / `Win+;` | Emoji/kaomoji/symbols panel |
| `Win+H` | Voice typing / dictation |
| `Win+Space` | Switch input language/keyboard layout |
| `Win+Shift+Space` | Switch input language backward |
| `Win+Ctrl+Space` | Switch to previously selected input |

---

## 6) Screenshots and screen recording

| Shortcut | Action |
|---|---|
| `Win+Shift+S` | Snipping overlay (region capture to clipboard) |
| `Win+PrtScn` | Full-screen screenshot to file |
| `Alt+PrtScn` | Screenshot of active window to clipboard |
| `Win+Shift+R` | Record a region (opens Snipping Tool recorder on supported builds) |

---

## 7) Taskbar: open pinned apps & instances

| Shortcut | Action |
|---|---|
| `Win+T` | Cycle through taskbar apps |
| `Win+1`..`Win+0` | Open/switch to pinned app in that taskbar slot |
| `Win+Shift+1`..`Win+Shift+0` | Open new instance of pinned app |
| `Win+Ctrl+1`..`Win+Ctrl+0` | Switch to last active window of pinned app |
| `Win+Alt+1`..`Win+Alt+0` | Open Jump List for pinned app |
| `Win+Ctrl+Shift+1`..`Win+Ctrl+Shift+0` | Open new instance as administrator |

## 11) Media keys (hardware / extended keyboard)

These are common “consumer” keys. They exist as virtual keys and are present on many keyboards/headsets.

| Key | Action |
|---|---|
| `Volume Up` | Increase volume |
| `Volume Down` | Decrease volume |
| `Mute` | Toggle mute |
| `Play/Pause` | Toggle playback |
| `Next Track` | Next |
| `Previous Track` | Previous |
| `Stop` | Stop |
